⚙️ Настройки Telegram для учителя

Результаты ДЗ отправляются через официальный бот @math6gradeZVEROK_bot.

Как учителю получать отчёты учеников:
1. Откройте Telegram и напишите боту @math6gradeZVEROK_bot команду /start.
2. Узнайте свой числовой Chat ID (например, написав боту @userinfobot).
3. Введите ваш Chat ID в поле ниже и нажмите «Проверить связь 🔔».
