# 📐 Интерактивный тренажёр по математике (6 класс) · ФГОС и ФОП

Интерактивный сайт-тренажёр по математике для учащихся 6 классов, полностью охватывающий школьную программу по стандартам ФГОС ООО и ФОП (УМК Виленкина, Мерзляка, Петерсон, Макарычева).

Включает **12 содержательных модулей**, **32 урока** (64 варианта: классные и домашние работы), **219 комплексных задач** и **276 интерактивных полей ввода** с мгновенной проверкой, а также теоретические памятки.

🌐 **Готовый сайт проекта:** [https://baikovaalina.github.io/math6-trenazhor/](https://baikovaalina.github.io/math6-trenazhor/)  
🤖 **Telegram-бот для приёма ДЗ:** [@math6gradeZVEROK_bot](https://t.me/math6gradeZVEROK_bot)

## 🚀 Особенности проекта

- **Красивая математическая типографика дробей:** Обыкновенные и смешанные дроби отображаются с **горизонтальной чертой деления** (знаменатель строго под числителем, смешанная часть выровнена по центру).
- **Безопасность (GitHub Secrets):** Токен бота и Chat ID учителя не хранятся в открытом виде в публичном коде репозитория. Они внедряются автоматически в процессе сборки GitHub Actions из зашифрованных секретов:
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_CHAT_ID`
- **100% бесплатно и без бэкенда:** Работает на GitHub Pages (чистый HTML5, CSS3, ES6 JavaScript).
- **Стилизация под тетрадь в клетку:** Аутентичный дизайн с полями, стикерами, удобным шрифтом и крупными кнопками.
- **Интеллектуальная проверка ответов:**
  - Поддержка обыкновенных дробей (`3/4`), смешанных чисел (`2 1/3`), десятичных дробей (`1,5` и `1.5`), отрицательных чисел (`-12`), списков чисел без учета порядка (`1, 2, 3`), координат (`(3; -2)`).
  - Мгновенная цветовая обратная связь: зелёный цвет при верном ответе, анимация и красный цвет при ошибке.
- **Автоматическое оценивание:** Подсчёт первичных баллов, процента выполнения и итоговой школьной оценки (2, 3, 4, 5) по официальной шкале ФГОС.
- **Интеграция с Telegram Bot API:**
  - Результаты ученика мгновенно приходят учителю в личные сообщения или в закрытую группу класса.
  - Сообщение содержит: ФИО ученика, название урока, время решения, набранные баллы, оценку и список допущенных ошибок.
- **Резервный вариант:** Возможность скачать подробный отчёт в текстовом файле (`.txt`) в один клик.

```text

│   └── workflows/
```

## 🤖 Настройка Telegram и секретов

В проекте настроен Telegram-бот **@math6gradeZVEROK_bot** и привязан Chat ID учителя `7928474241`.

Секреты зашифрованы и хранятся в **Settings ➔ Secrets and variables ➔ Actions**:
1. `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
2. `TELEGRAM_CHAT_ID` — Chat ID учителя для доставки отчётов.

При каждом обновлении в ветке `main` GitHub Actions автоматически собирает проект, подставляет значения секретов и публикует обновлённую версию на GitHub Pages.
