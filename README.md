# 📐 Интерактивный тренажёр по математике (6 класс) · ФГОС и ФОП (УМК Виленкина)

Интерактивный сайт-тренажёр по математике для учащихся 6 классов, полностью охватывающий школьную программу по стандартам ФГОС ООО и ФОП (УМК Виленкина, Мерзляка, Петерсон, Макарычева).

Включает **12 содержательных модулей**, **32 урока** (64 варианта: классные и домашние работы), **3 полноценных пробных ВПР на время (60 мин)**, **335 комплексных задач** и **338 интерактивных полей ввода** с мгновенной проверкой ответов.

🌐 **Готовый сайт проекта:** [https://baikovaalina.github.io/math6-trenazhor/](https://baikovaalina.github.io/math6-trenazhor/)  
🤖 **Telegram-бот для приёма ДЗ и ВПР:** [@math6gradeZVEROK_bot](https://t.me/math6gradeZVEROK_bot)

## 🚀 Особенности и новшества проекта

- **🚫 Никаких подсказок в работах:** Полное отсутствие подсказок и спойлеров в классных, домашних работах и пробниках ВПР для честного контроля знаний.
- **⏱️ Пробные ВПР по математике на время (60 минут):**
  - 3 полноценных тренировочных варианта по 13 официальных заданий ВПР (Демоверсия ФИОКО, Основной тренировочный, Повышенной сложности);
  - Интерактивный таймер обратного отсчёта на 60 минут с пульсирующим предупреждением при остатке менее 5 минут;
  - Автоматическое завершение и оценка по официальной шкале перевода первичных баллов ФИОКО (0–5: «2», 6–9: «3», 10–11: «4», 12–13: «5»);
  - Мгновенная отправка результатов ВПР учителю в Telegram с фиксацией затраченного времени.
- **📚 Минимум 16–39 задач на каждый модуль курса:** Каждый из 12 модулей 6 класса обеспечен глубоким банком типовых и усложнённых упражнений.
- **📐 Безупречная математическая типографика (KaTeX):** Обыкновенные и смешанные дроби отображаются с горизонтальной чертой деления (числитель строго над знаменателем).
- **Безопасность (GitHub Secrets):** Токен бота и Chat ID учителя не хранятся в открытом виде в публичном коде репозитория. Они внедряются автоматически в процессе сборки GitHub Actions из зашифрованных секретов:
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_CHAT_ID`
- **100% бесплатно и без бэкенда:** Работает на GitHub Pages (чистый HTML5, CSS3, ES6 JavaScript).
- **Стилизация под тетрадь в клетку:** Аутентичный дизайн с полями, удобным шрифтом и крупными кнопками.
- **Интеллектуальная проверка ответов:**
  - Поддержка обыкновенных дробей (`3/4`), смешанных чисел (`2 1/3`), десятичных дробей (`1,5` и `1.5`), отрицательных чисел (`-12`), списков чисел без учета порядка (`1, 2, 3`), координат (`(3; -2)`).
  - Мгновенная цветовая обратная связь: зелёный цвет при верном ответе, анимация и красный цвет при ошибке.
- **Резервный вариант:** Возможность скачать подробный отчёт в текстовом файле (`.txt`) в один клик.

```text
└── README.md            # Документация и инструкция
```

## 🤖 Настройка Telegram и секретов

В проекте настроен Telegram-бот **@math6gradeZVEROK_bot** и привязан Chat ID учителя `7928474241`.

Секреты зашифрованы и хранятся в **Settings ➔ Secrets and variables ➔ Actions**:
1. `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
2. `TELEGRAM_CHAT_ID` — Chat ID учителя для доставки отчётов.

При каждом обновлении в ветке `main` GitHub Actions автоматически собирает проект, подставляет значения секретов и публикует обновлённую версию на GitHub Pages.
